Matt's Tool Help

Version 2026-07-13 v06 · Released July 13, 2026

The personal song library, editing, transpose, font sizing and auto-scroll work offline after the app has been opened successfully online once. Google Drive and Community features require internet.

Playing on phone or iPad

  • Tap ♫ or tap the song area to show large playing controls.
  • The controls hide automatically after about 4.5 seconds so the chord sheet uses the maximum screen area.
  • Tap again whenever you need transpose, speed, font size or edit controls.
  • Starting Auto Scroll hides the library automatically.

Library and editing

  • Use Manual to add a song or ✏ Edit to update the current song.
  • Song-specific transpose, speed and font size are saved automatically.
  • JSON Backup is the recommended portable backup. It includes songs and display settings.
  • Save File creates a standalone HTML copy for archival use.

Backup and restore

  • Drive Backup/Restore: sign into Google and store or retrieve the JSON file. Internet required.
  • JSON Backup/Restore: download or select a local JSON file. Works without internet.
  • Restore updates matching songs and adds songs not already in the library.

Community

Community browsing and sharing use GitHub and therefore require internet. Never paste a GitHub token into the source code. A token entered in Settings stays only in that browser's local storage.

Offline installation

iPhone/iPad: open in Safari, tap Share, then Add to Home Screen. Android/Desktop: use the browser's Install App command. Open the app online once after each update so the newest release is cached.

Keyboard shortcuts

  • Space: start or stop auto-scroll
  • Shift + ↑/↓: transpose
  • R: reset transpose
